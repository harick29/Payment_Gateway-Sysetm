# Math2Money Frontend

Frontend dashboard for the Math2Money application.

## Features

- Dashboard
- Question of the Day
- Easy, Medium and Hard challenges
- Random math questions
- Reward system
- Celebration popup for correct answers
- Wallet
- Transaction history
- User profile
- Responsive UI

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Installation

Clone the repository:

git clone <repository-link>

Install dependencies:

npm install

Run the development server:

npm run dev
