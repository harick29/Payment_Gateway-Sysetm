# Payment Gateway Integration using Node.js

## About the Project

I created this project to learn about payment gateways and understand how online payments work in real-world applications. I wanted to know how a website processes a payment, communicates with a payment gateway, and verifies whether a transaction was successful.

To practice this, I developed a web application called Math2Money. It is a math-based application where users can solve challenges, earn virtual rewards, manage their wallet, and explore payment gateway integration using Razorpay.

The main idea behind this project was to gain practical experience with payment processing and understand how the frontend, backend, and database work together in a full-stack application.

## What is a Payment Gateway?

A payment gateway is a service that helps websites and applications accept online payments. It connects an application with a payment service provider to process transactions securely.

For example, when a user makes a payment on a website, the application creates a payment request, the payment gateway processes it, and the backend verifies the result before updating the transaction details.

## Features

- Users can solve math challenges of different difficulty levels.
- Rewards are given for correctly answering questions.
- Users can view their wallet balance and transaction history.
- Razorpay is integrated to explore the online payment process in test mode.
- PostgreSQL is used to store application data.
- Withdrawals can be tested through a simulated process.

## Technologies Used

- Frontend: React.js and Vite
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Payment Gateway: Razorpay
- Tools: VS Code and GitHub

## What I Learned

While working on this project, I learned how a payment gateway can be integrated into a web application using Node.js. I also gained experience in creating REST APIs, connecting the frontend with the backend, working with PostgreSQL, creating payment orders, and verifying payment responses.

This project helped me understand the basic payment workflow and gave me an opportunity to apply my full-stack development knowledge in a practical application.

## Future Improvements

I would like to improve the application by adding user authentication, strengthening transaction handling, and exploring more payment features and secure payout integration.

## Conclusion

I built this project mainly to understand payment gateway integration through practical implementation rather than just learning the concepts theoretically. It helped me explore how online payment workflows work and how different parts of a full-stack application communicate with each other.

This is a learning project, and payments are tested using Razorpay Test Mode. Withdrawals are simulated and do not transfer real money.
